# MCP Marketplaces

You.com is available as an MCP server, letting AI agents and LLM-powered tools call live web search directly with no custom glue code required.

#### [Databricks](https://marketplace.databricks.com/details/32d5b7b6-0fab-4bba-9c57-5de23dd58996/Youcom_Youcom-MCP-The-1-AI-Web-Search-API)

Available on Databricks Marketplace to procure and deploy You.com MCP alongside your lakehouse workflows.

#### [Anthropic MCP Registry](https://registry.modelcontextprotocol.io/?q=io.github.youdotcom-oss%2Fmcp)

Officially listed in the MCP registry as `io.github.youdotcom-oss/mcp`.

#### [PulseMCP](https://pulsemcp.com/servers/youcom)

Listed in PulseMCP's server directory for teams browsing MCP servers.

#### [Glama](https://glama.ai/mcp/servers/@jimbul/youdotcom_MCP)

Available on Glama's MCP server directory for AI developers.

#### [MCP Market](https://mcpmarket.com/server/you-com)

Listed on MCP Market for teams browsing server options by use case.

#### [Composio](https://docs.composio.dev/toolkits/yousearch)

Accessible via Composio's toolkit as `yousearch` for agent tool integrations.

#### [Warp](https://warp.dev/download)

Available in Warp's agent platform MCP directory for agentic workflows.
