# Cloud Marketplaces

You.com APIs are available through major cloud marketplaces, making it easier for enterprise teams to procure, deploy, and scale AI-powered search within their existing cloud contracts.

#### [AWS Marketplace: Web Search API](https://aws.amazon.com/marketplace/pp/prodview-vflktegcmcueo)

Available on AWS Marketplace with an active co-sell motion for enterprise accounts.

#### [AWS Marketplace: Research API](https://aws.amazon.com/marketplace/pp/prodview-q2l6errpx4a2u)

Deep research capabilities available via AWS Marketplace alongside the Web Search API.

#### [Azure Marketplace: Web Search API](https://marketplace.microsoft.com/en-us/product/youcom.you-azure-websearch)

Listed on Microsoft Azure Marketplace for teams building on Azure AI infrastructure.

#### [Azure Marketplace: Research API](https://marketplace.microsoft.com/en-us/product/youcom.you-azure-research)

Research API available on Azure Marketplace for AI teams needing grounded, cited answers at scale.

#### [Azure Marketplace: Finance Research API](https://marketplace.microsoft.com/en-us/product/saas/youcom.you-azure-finance-research?tab=Overview)

Finance Research API available on Azure Marketplace for financial AI teams needing grounded, cited answers at scale.
