# Framework and Tool Partners

You.com connects with the AI orchestration frameworks and developer tools your team is already building on, from agent frameworks to workflow automation and LLM SDKs.

This page tracks partner ecosystem presence. For implementation guides and code examples, use the [Integrations](/docs/integrations) section.

## AI Frameworks and SDKs

#### [OpenAI GPT OSS](/docs/integrations/gpt-oss)

Referenced in the OpenAI GPT OSS repo as a compatible web search data source.

#### [LangChain](/docs/integrations/langchain)

Native LangChain tool integration to add You.com search to chains and agents.

#### [LangGraph](/docs/integrations/langgraph)

Available via the `langchain-youdotcom` package for LangGraph stateful agent workflows.

#### [Vercel AI SDK](/docs/integrations/vercel-ai-sdk)

Plugin available through `dx-toolkit` for teams shipping AI features with the Vercel AI SDK.

#### [LlamaIndex](/docs/integrations/llamaindex)

You.com retriever available in LlamaIndex for RAG pipelines that need fresh web context.

#### [crewAI](/docs/integrations/crewai)

Official tool integration for crewAI agents to give your crew live web search.

#### [LiteLLM](https://docs.litellm.ai/docs/search/you_com)

LiteLLM integrates You.com as a native search provider for real-time web search in AI workflows.

#### [Temporal](/docs/integrations/temporal)

Durable execution plugin that wraps every You.com API as crash-resistant Temporal activities.
