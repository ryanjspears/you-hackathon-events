# Hackathon brief — official getting-started info

Posted by the organizers (Madison Lee), 2026-09-11. Verbatim requirements and rubric; treat as the source of truth for what must ship.

## Theme: Self-Improving and Learning Agents

Build an AI agent that improves through feedback, experience, or new information.

Your agent might learn a user's preferences, improve its results after feedback, remember what worked, adapt when a tool fails, or change its approach based on live web data.

You don't need to build a fully autonomous learning system. A focused prototype that demonstrates how your agent improves is enough.

## Requirements

- Public GitHub repo — organized, with a README that covers setup
- 1–3 minute YouTube demo video
- 200-word description — problem, tech stack, API use
- At least one You.com API endpoint in the build; must use ALL three partners: CrewAI, Daytona, and One
- Must use Clean Data
- One submission per team

## Judging criteria (each scored 1–5)

| Criterion | What they ask |
| --- | --- |
| Completed the loop | Did the agent go past producing an answer and change something in a real system? |
| Technical implementation | API integration, architecture, code quality. |
| Innovation & originality | Novel use of the stack. |
| Impact & relevance | Solves a real problem with a plausible use case. |
| Presentation & documentation | Clear demo and reproducible repo. |
